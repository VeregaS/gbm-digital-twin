# Эксперименты

`solver/` — синтетические численные проверки и benchmarks; `calibration/` — диагностика V2; `cohort/` и `treatment/` — анализ сохраненных исследований. `archived/` — исторические входные скрипты V1/V2; они сохранены, поскольку используют прежние public model APIs и документируют воспроизведение результатов.

Для новых операций использовать соответствующие команды `scripts/twin/` и `gbm_twin.cli`. Не переносить устойчивую domain logic в experiments. Наличие исторического скрипта не является разрешением повторно открывать закрытые cohorts или подбирать параметры по раскрытым outcomes. Generated data/results/cache не коммитятся.
