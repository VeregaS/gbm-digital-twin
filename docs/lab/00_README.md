## Состав

- 01_TECHNICAL_SPEC.md / .html — один нормативный документ, 28 разделов, 16 use cases, 13 checkpoints CP00–CP12, атомарная приемка.
- 02_REQUIREMENTS.csv — тот же реестр MUST, UTF-8 BOM; каждый ID имеет checkpoint и AT-ID.
- 03_RESEARCH_BASIS.md — актуальность, 12 групп первоисточников, близкие работы и границы novelty claims.
- 04_AGENT_START.md — инструкция запуска и продолжения работы без ухода в unrelated scope.
- 05_PROGRESS_TEMPLATE.md — незаполненный журнал реализации, все CP pending.
- 06_STUDY_PROTOCOL_DRAFT.json — draft scaffold научной серии, null поля требуют заполнения до freeze.
- 07_ACCEPTANCE_TRACKER.csv — начальная таблица evidence и статусов.
- 08_VALIDATION_REPORT.md — проверка самого пакета ТЗ; это не приемка будущего приложения.
- MANIFEST.json / SHA256SUMS.txt — состав и контрольные суммы пакета.

## Обязательные границы

Текущая база: feat/twin-protocol, audited HEAD e6ccf399ceb85d37c891ce053f631e5706bbef6b. Проверить фактический Git при старте. Первый релиз работает без CFB/атласа. Сохраняются negative Stage 10 result и закрытые reserve/holdout. Первая реализация использует pinned TumorTwin и synthetic author case. Хранение и ресурсы ограничены. Новая модель, облачная платформа и клиническая validation не являются скрытыми зависимостями.

Актуальность темы подтверждает необходимость исследования, но не первенство методов. Статьи и их принятие не обещаны. Полный разбор ближайших работ и statement of contribution — обязательный CP01 до больших серий.

## Как передать в новый чат

Передать весь архив и ссылку на репозиторий. Дать явное поручение реализовать проект по `04_AGENT_START.md`. Новая нейросеть начинает с CP00, проверяет фактическое окружение и закрывает requirements evidence. Один этот пакет не разрешает публикацию сайта, передачу restricted assets или отправку рукописей.
